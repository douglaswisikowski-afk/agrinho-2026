# Agro Forte, Futuro Sustentável 🌱

**Tema:** "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"

Este projeto é um site educativo sobre sustentabilidade no agronegócio, criado como atividade escolar do programa Agrinho. O objetivo é conscientizar sobre a importância de unir produção agrícola com preservação ambiental.

---

## Conteúdo do Site

O site contém:

- **Menu de navegação**: acesso rápido às seções do site.
- **Banner principal**: mensagem de impacto sobre agro sustentável.
- **Seção Sobre**: explica o tema e sua importância.
- **Cards de Benefícios**: mostra vantagens da produção sustentável.
- **Galeria de imagens**: fotos do campo e natureza.
- **Formulário de contato**: para enviar mensagens.
- **Interatividade com JavaScript**: botões que mostram mensagens.
- **Design responsivo e moderno**: para computadores e dispositivos móveis.

---

## Tecnologias Utilizadas

- **HTML5**: estrutura do site
- **CSS3**: estilo, cores, layout e efeitos
- **JavaScript**: interatividade (alertas, animações simples)
